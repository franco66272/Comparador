TECNORADAR V4.11

Rediseño de interfaz inspirado en comparadores modernos como HardGamers, sin copiar identidad visual.

CAMBIOS
- Portada reorganizada para destacar búsqueda, producto destacado, categorías, tiendas, oportunidades y catálogo.
- Diseño responsive desde el inicio para PC, tablet y celular.
- Barra de navegación compacta y menú de categorías.
- Banda de categorías populares.
- Fila de tiendas con logos y "Mostrar más" para el resto.
- Tarjetas de producto más compactas y orientadas a comparación de precio.
- Sección "Bajaron de precio".
- Ficha de producto reorganizada con precio destacado, fuente oficial, descripción e historial.
- Footer estructurado.
- El enlace "Ver todos" con orden/filtros ahora abre correctamente el catálogo en vez de volver a la portada.
- Se conserva el motor de scraping, catálogo, historial y verificación de precios existentes.

IDENTIDAD
- Nombre visual: TecnoRadar.
- Las claves internas de tiendas no fueron modificadas.
